# دوباره 🌿

ویترین آنلاین وسایل دست دوم — کارت‌های محصول، ثبت درخواست با شماره تماس، رزرو خودکار ۶ ساعته، پنل مدیریت و اعلان تلگرام.

ساخته‌شده با Next.js 16 + PostgreSQL + Drizzle ORM + Tailwind، آماده‌ی اجرا با Docker.

---

## ✨ امکانات

- 🛍 ویترین کارت‌محور با فیلتر دسته‌بندی، کاملاً فارسی و ریسپانسیو
- 📝 فرم خرید: شماره موبایل (الزامی) + نام و پیام (اختیاری)
- ⏳ رزرو خودکار ۶ ساعته بعد از ثبت درخواست؛ اگر معامله نشود خودکار آزاد می‌شود
- 🔔 اعلان فوری هر درخواست به تلگرام شما
- ☎️ بعد از ثبت موفق، شماره تماس و دکمه‌ی تلگرامِ شما به خریدار نمایش داده می‌شود
- 🖼 آپلود مستقیم عکس در پنل (فشرده‌سازی خودکار + نسخه‌ی کوچک با sharp)
- 🛡 ضد اسپم: سقف ارسال فرم برای هر IP + قفل ورود بعد از تلاش‌های ناموفق
- 🔒 پنل مدیریت با رمز، SSL خودکار با Caddy

## 🚀 نصب روی سرور (۵ قدم)

### پیش‌نیازها
- یک سرور لینوکس (اوبونتو/دبیان) با دسترسی SSH
- یک دامنه
- Docker و Docker Compose:
  ```bash
  curl -fsSL https://get.docker.com | sh
  ```

### قدم ۱ — دریافت پروژه
```bash
git clone https://github.com/hadiranweb/dobare.git
cd dobare
```

### قدم ۲ — تنظیم `.env`
```bash
cp .env.example .env
nano .env
```
تمام متغیرها داخل فایل توضیح داده شده‌اند. مهم‌ترین‌ها:
| متغیر | توضیح |
|---|---|
| `POSTGRES_PASSWORD` | رمز دیتابیس — قوی انتخاب کنید و همان را در `DATABASE_URL` بگذارید |
| `DOMAIN` | دامنه‌ی شما، مثل `dobare.ir` |
| `ACME_EMAIL` | برای گواهی SSL رایگان |
| `ADMIN_PASSWORD` | رمز ورود به `/admin` |

### قدم ۳ — اتصال دامنه
در پنل مدیریت دامنه، یک رکورد **A** بسازید که به IP سرور اشاره کند. (تا این رکورد فعال نشود، SSL صادر نمی‌شود.)

### قدم ۴ — اجرا
```bash
docker compose up -d --build
```
همین! چهار کانتینر بالا می‌آیند:
| کانتینر | وظیفه |
|---|---|
| `postgres` | دیتابیس (روی volume، بدون از دست رفتن داده) |
| `migrate` | ساخت/به‌روزرسانی جداول (یک‌بار اجرا می‌شود) |
| `app` | سایت دوباره |
| `caddy` | SSL خودکار + سرو روی پورت 80/443 |

### قدم ۵ — ورود به مدیریت
به `https://دامنه-شما/admin` بروید و با `ADMIN_PASSWORD` وارد شوید. اولین وسیله را اضافه کنید — تمام!

## 🤖 تنظیم بات تلگرام (اختیاری ولی توصیه‌شده)

1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام بدهید: `/newbot` و مراحل را بروید ← توکن را بردارید
2. یک پیام به بات خودتان بفرستید (مثلاً «سلام»)
3. این آدرس را در مرورگر باز کنید: `https://api.telegram.org/bot<توکن>/getUpdates` و مقدار `chat.id` را بردارید
4. هر دو را در `.env` بگذارید و `docker compose up -d` بزنید

## 💾 بکاپ

همه‌ی داده‌های شما در پوشه‌ی `data/` پروژه است (دیتابیس + عکس‌ها). بکاپ کامل:

```bash
./scripts/backup.sh
```

بکاپ خودکار شبانه (ساعت ۳ بامداد) — `crontab -e`:
```
0 3 * * * cd /path/to/dobare && ./scripts/backup.sh >> backups/backup.log 2>&1
```

بازگردانی دیتابیس:
```bash
gunzip -c backups/db-تاریخ.sql.gz | docker compose exec -T postgres psql -U dobare dobare
```

## 🔄 به‌روزرسانی

```bash
git pull
docker compose up -d --build
```
داده‌ها دست‌نخورده می‌مانند (روی volume هستند، نه داخل کانتینر).

## 🩺 رفع اشکال

```bash
docker compose ps                 # وضعیت کانتینرها
docker compose logs -f app        # لاگ سایت
docker compose logs -f caddy      # لاگ SSL/وب‌سرور
docker compose restart app        # ری‌استارت
```
- **SSL صادر نشد؟** رکورد A دامنه را چک کنید؛ سپس `docker compose restart caddy`
- **پورت 80/443 اشغال است؟** سرویس وب‌سرور قبلی (nginx/apache) را خاموش کنید
- **سلامت سایت:** `https://دامنه-شما/api/health` باید `{"ok":true}` بدهد

## 📁 ساختار داده‌ها

```
data/
├── postgres/    ← فایل‌های دیتابیس
├── uploads/     ← عکس‌های وسایل (اصلی + نسخه کوچک)
├── caddy/       ← گواهی‌های SSL
backups/         ← خروجی اسکریپت بکاپ
```

## 🛠 توسعه‌ی محلی (بدون داکر)

```bash
npm install
# PostgreSQL در حال اجرا + تنظیم DATABASE_URL در .env
npm run migrate     # ساخت جداول
npm run dev         # http://localhost:3000
```
